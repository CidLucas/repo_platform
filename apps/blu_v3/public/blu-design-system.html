Documentação v3

Blu — Design System & Wireframes

Este documento padroniza todos os tokens, componentes e telas do blu v3 — o escritório virtual com IA para empresas brasileiras. Use-o como referência única para implementar novas features, revisar PRs visuais e alinhar produto/design/engenharia.

🎨Identidade

Marca em gradiente roxo→azul, glassmorphism escuro, vibe "escritório noturno".

🧱Stack técnica
  • • React 18 + Vite
  • • React Router 6
  • • TanStack Query v5
  • • Zustand (UI state)
  • • Phosphor Icons
  • • CSS vanilla + custom properties

📐Princípios de design

Humano-no-comando

IA prepara, humano decide. Nada acontece sem aprovação visível.

Densidade informacional

Power-user app: alta densidade, hierarquia clara, sem whitespace inútil.

Glass & depth

Painéis translúcidos, blur 16-24px, sombras inset sutis para hierarquia.

Roxo = Blu

Acento roxo reservado para CTAs primários, estado ativo e insights de IA.
