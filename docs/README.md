## Arquivados (`archive/`)

Documentos de planejamento já executados, backlog antigo, snapshots pontuais e duplicatas. Preservados para referência histórica, não refletem o estado atual.

## Convenção

- Docs em inglês; seções de decisão e filosofia podem ser em português
- Ao implementar uma feature, atualizar o doc relevante antes de fechar o PR
- Docs de planejamento (backlogs, fix plans) vão para `archive/` após execução
- Snapshots autogenerated (auto-agent-types, auto-skills) não ficam em docs/ — são gerados sob demanda
