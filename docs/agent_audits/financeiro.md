## Agent Logical Map

The **financeiro** agent is a **read-only financial intelligence layer** for the Blu platform. Its typical flow:

1. **Entry**: Activated via platform routing when user intent involves financial data (revenue queries, cash flow, weekly/monthly snapshots, ticket médio).
2. **Tool selection**:
   - If business context is needed → `executar_rag_cliente` first to ground the analysis
   - For all numeric queries → `execute_sql` against `analytics_v2.fato_transacoes`
3. **Period defaulting**: No period specified → last 7 days (weekly) or 30 days (general).
4. **Anomaly detection**: Automatically flags > 15% period-over-period drops.
5. **Output**: Tabular for multi-period comparisons; structured weekly snapshot format for routine reports.

**Handoffs**:
- → **data-entry** agent: when user wants to *register* a transaction (write path strictly forbidden here)
- → **CRM** agent: when customer delinquency or collections arise
- ← **financeiro_monitor routine**: uses `finance_monitor_report` skill to generate automated financial health snapshots injected with pre-fetched context variables

**Relationship to other agents**: The financeiro agent is purely analytical. It does not create data. It feeds insights to the **strategy** agent (for growth decisions) and receives context from the **context-gatherer** (company profile, targets). It is the primary consumer of `analytics_v2.fato_transacoes`.
