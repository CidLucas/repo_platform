# Blu Models

This library is the single source of truth for all Blu data models.

## Overview

The Blu Models library defines the data structures used throughout the Blu application. It uses [SQLModel](https://sqlmodel.tiangolo.com/) to create models that are both SQLAlchemy models and Pydantic models.

This library ensures that data is consistent and validated across all services.

### Key Technologies

- **Data Modeling:** SQLModel
- **Package Manager:** Poetry
