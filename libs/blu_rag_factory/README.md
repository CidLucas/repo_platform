# Blu RAG Factory

This library provides a factory for creating Retrieval-Augmented Generation (RAG) runnables and tools for the Blu application.

## Overview

The Blu RAG Factory simplifies the process of creating and configuring RAG-based tools. It uses `langchain-core` and other internal Blu libraries to create custom RAG chains that can be used by the `atendente_core` service.

### Key Technologies

- **RAG:** LangChain
- **Package Manager:** Poetry
