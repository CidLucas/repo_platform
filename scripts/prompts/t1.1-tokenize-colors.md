# T1.1 — Inventariar e promover cores off-palette a tokens em global.css

## Contexto

O `global.css` em `apps/blu_v3/src/styles/global.css` define ~30 variáveis CSS de cor em `:root` (e equivalentes em `body.light`). A auditoria do design system detectou que centenas de componentes usam cores hex/rgba literais em vez de `var(--...)`. A correção completa (substituição literal→token) está na Fase 3. **Nesta task, criamos os tokens que faltam** — a Fase 3 só vai trocar literais por `var(--nome)`.

## O que fazer

Arquivos-alvo (dentro de `apps/blu_v3/src/`):

- `styles/onboarding.css` — cores de marca
- Todos os `pages/app/*.tsx` e `components/**/*.tsx`

### 3. Adicionar os tokens em global.css

No bloco `:root`, adicionar os novos tokens **após os tokens existentes** (`--chart-8` e seguintes). Manter agrupamento lógico:

```css
:root {
  /* ... existing tokens ... */
  
  /* brand */
  --brand-orange: #FF5701;
  
  /* extended palette */
  --violet:     #8B5CF6;
  --att-soft:   #FBBF24;
  --att-dark:   #CA8A04;
  --ok-dark:    #16A34A;
  --ok-bright:  #22C55E;
  --orange:     #FB923C;
  --orange-500: #F97316;
  --slate-400:  #94A3B8;
  --teal:       #34D399;
  --teal-400:   #2DD4BF;
  --pink:       #F472B6;
  --indigo-500: #6366F1;
  --urg-soft:   #F87171;
  --light-bg:   #E8EDF8;
  
  /* external brand colors */
  --google-blue:  #4285F4;
  --slack-red:    #E01E5A;
  --slack-blue:   #36C5F0;
  --slack-green:  #2EB67D;
  --slack-yellow: #ECB22E;
  --integ-blue:    #4A90D9;
  --integ-blue-alt:#3A80D4;
  --integ-purple:  #7B68EE;
  
  /* overrides existentes – manter */
  --chart-8: var(--violet);
}
```

No bloco `body.light`, adicionar equivalents (mais escuros/claros) se fizer sentido. Para cores de marca externa (Google, Slack), manter o mesmo valor.

Para `--brand-orange`, definir um tom mais escuro no light theme:
```css
body.light {
  /* ... */
  --brand-orange: #E04E00;
}
```

Adicionar usando `color-mix`:
```css
--violet-dim: color-mix(in srgb, var(--violet) 15%, transparent);
--brand-orange-dim: color-mix(in srgb, var(--brand-orange) 15%, transparent);
```

3. Os 3 temas (dark padrão, body.light, prefers-contrast) devem funcionar
