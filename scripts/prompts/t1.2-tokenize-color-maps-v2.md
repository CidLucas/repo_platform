# T1.2 — Tokenizar mapas de cor (apenas tokens do spec)

## Contexto

A T1.1 adicionou ao global.css os tokens que estavam no spec mas faltavam no código. Agora podemos referenciá-los nos mapas de cor dos componentes.

**Tokens disponíveis (do spec):**
- `--blue3` (#818cf8) — já existia
- `--blue2` (#3B82F6) — já existia
- `--orange` (#fb923c) — adicionado na T1.1
- `--violet` (#a78bfa) — adicionado na T1.1

**Cores SEM token no spec → NÃO substituir, manter hex literal.**
- `#F06A6A` (asana) — sem token, manter
- `#5E6AD2` (linear) — sem token, manter
- `#4285F4` (google) — sem token, manter
- `#6b7280` (fallback) — sem token, manter

## Mudanças

### 1. `apps/blu_v3/src/pages/app/AgendaRoom.tsx`

**Linha 42-45** — DOT_COLORS:
```ts
const DOT_COLORS: Record<string, string> = {
  approval: '#fb923c',    // → 'var(--orange)'
  calendar: '#818cf8',    // → 'var(--blue3)'
}
```

**Linha 195** — fallback:
```ts
background: DOT_COLORS[ev.agenda_source] ?? '#818cf8'
```
→
```ts
background: DOT_COLORS[ev.agenda_source] ?? 'var(--blue3)'
```

**Linha 294** — fallback:
```ts
background: DOT_COLORS[ev.agenda_source] ?? '#818cf8'
```
→
```ts
background: DOT_COLORS[ev.agenda_source] ?? 'var(--blue3)'
```

### 2. `apps/blu_v3/src/components/agenda/MonthlyGantt.tsx`

**Linha 58-66** — ROUTINE_COLORS (todas '#8b5cf6' → 'var(--violet)'):
```ts
const ROUTINE_COLORS: Record<string, string> = {
  Financeiro:  '#8b5cf6',     // → 'var(--violet)'
  Compras:     '#8b5cf6',     // → 'var(--violet)'
  Clientes:    '#8b5cf6',     // → 'var(--violet)'
  Agenda:      '#8b5cf6',     // → 'var(--violet)'
  Documentos:  '#8b5cf6',     // → 'var(--violet)'
  'Estratégia':'#8b5cf6',     // → 'var(--violet)'
  Geral:       '#8b5cf6',     // → 'var(--violet)'
}
```

Nota: --violet no spec é #a78bfa, um tom mais claro que #8b5cf6. Isso é intencional — o spec é a referência.

**Linha 68-74** — SOURCE_COLORS (substituir APENAS os que têm token):
```ts
const SOURCE_COLORS: Record<string, string> = {
  monday: '#3b82f6',     // → 'var(--blue2)'
  notion: '#3b82f6',     // → 'var(--blue2)'
  asana:  '#F06A6A',     // → manter (sem token)
  linear: '#5E6AD2',     // → manter (sem token)
  google: '#4285F4',     // → manter (sem token)
}
```

**Linha 781** — fallback (manter, sem token):
```ts
const srcColor = SOURCE_COLORS[project.source] ?? '#6b7280'
```
→ manter (sem token para #6b7280)

## Verificação

1. `npx tsc --noEmit` — sem erros novos
2. Apenas `var(--...)` para tokens que existem: --blue2, --blue3, --orange, --violet
3. Cores sem token (#F06A6A, #5E6AD2, #4285F4, #6b7280) permanecem como hex
