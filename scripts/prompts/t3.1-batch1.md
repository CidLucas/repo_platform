## Contexto

Substituindo hex/rgba literais por `var(--...)` tokens do spec. Usar `color-mix` para RGBA derivados.

**Critério de aceite:** `grep -Ein '#[0-9a-fA-F]{3,8}|rgba\('` nos arquivos modificados = 0 ocorrências (exceto exceções documentadas no spec).

## Regras

- Em JSX inline (style={{...}}): usar `'var(--tok)'` (string)
- Em CSS: usar `var(--tok)`
- color-mix: manter a sintaxe `color-mix(in srgb, var(--tok) N%, transparent)`
- **Não modificar** as exceções documentadas
