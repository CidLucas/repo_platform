# T4.1 — Batch 1: Substituir SVGs inline por Icons.tsx

## Contexto

O spec define Phosphor Icons como padrão. O módulo `components/shared/Icons.tsx` exporta 14 ícones com `size=14`, `weight='regular'`, `currentColor`.

**Regra:** Substituir APENAS SVGs inline cujo path corresponde semanticamente a um dos ícones do módulo. SVGs complexos (logotipos, gráficos, gradientes) NÃO substituir.

## Regras

- SVG inline simples (paths retos, sem gradientes, sem viewBox complexo) → substituir
- SVG de logotipo, gráfico, ilustração → NÃO substituir
- Em JSX: `<IconNome />` em vez de `<svg>...</svg>`
- Adicionar import de `'../shared/Icons'` (ajustar path conforme profundidade)
- Tamanho padrão 14 (ícones do módulo), mas ChatPanel.CloseIcon usa 16
