# T4.2 — Adotar .btn nos botões fora do padrão

## Contexto

O global.css tem classes `.btn` (botão base), `.btn-p` (roxo/primário), `.btn-s` (cinza/secundário), `.btn-g` (ghost), `.btn-sm`, `.btn-lg`. Vários arquivos usam `style={{...}}` inline em vez dessas classes.

### 1. `components/onboarding/FirstRunOverlay.tsx`

**Pills de sugestão** (linha 212):
```tsx
// Atual: style inline (borderRadius: 12, padding: '5px 11px', etc.)
<button style={{...}}>
```
→ Substituir por:
```tsx
<button className="btn btn-sm btn-ghost" onClick={() => handlePill(p)}>
```
Remover os handlers onMouseEnter/onMouseLeave (o hover do `.btn-ghost` já cuida disso).

**CTA "Entrar no escritório"** (linha 243):
```tsx
// Atual: style inline (background: 'var(--ac)', padding: '10px 16px', width:'100%')
```
→ Substituir por:
```tsx
<button className="btn btn-primary" onClick={dismiss} style={{ width: '100%' }}>
```
(manter width:100% porque é específico do layout, não do botão)

### 2. `components/chat/ChatPanel.tsx`

**Close button** (linha ~225):
```tsx
// Atual: style inline (padding: 5px, borderRadius: 6)
```
→ Substituir por:
```tsx
<button className="ibtn">
```
(a classe `.ibtn` já está definida em global.css com width:28px, height:28px, border-radius:6px)

### 3. `components/onboarding/ConnectionsModal.tsx`

**Option cards** (itens de conexão, linha ~50):
```tsx
// Atual: style inline com borderRadius: 8, padding: '14px 12px', etc.
```
→ Substituir:
- O container grid mantém o layout
- Cada card vira um `<button>` com className `btn` e style mínimo

## Regras
- Usar className existente do global.css
- Remover onMouseEnter/onMouseLeave manuais (o CSS já faz hover)
- Manter style APENAS para propriedades de layout não cobertas pelo CSS (.btn)
- Adicionar import removido se necessário
