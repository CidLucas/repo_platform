# T4.3 — Migrar overlays para Modal compartilhado (AdminScreen)

## Substituições

### 1. Invite modal em `pages/app/AdminScreen.tsx` (~linha 608)

**Antes:**
```tsx
{showInviteModal && (
  <div
    style={{ position: 'fixed', inset: 0, background: '#0008', zIndex: 200, display: 'flex', alignItems: 'center', justifyContent: 'center' }}
    onClick={() => setShowInviteModal(false)}
  >
    <div style={{ background: 'var(--bg)', borderRadius: 14, padding: 24, width: 320, boxShadow: '0 8px 32px #0004' }} onClick={e => e.stopPropagation()}>
      <div style={{ fontSize: 14, fontWeight: 700, marginBottom: 16 }}>Adicionar usuário</div>
      {/* form content */}
      <div className="modal-acts" style={{ marginTop: 16 }}>
        <button className="btn bs" onClick={() => setShowInviteModal(false)}>Cancelar</button>
        <button className="btn bp" onClick={handleInvite} style={{ opacity: inviteUser.isPending ? 0.6 : 1 }} disabled={inviteUser.isPending}>Convidar</button>
      </div>
    </div>
  </div>
)}
```

**Depois:**
```tsx
import Modal from '../../components/shared/Modal'

{/* No lugar do overlay */}
<Modal open={showInviteModal} onClose={() => setShowInviteModal(false)} title="Adicionar usuário">
  {/* form content (mesmo conteúdo, sem o header/title duplicado) */}
  <div className="modal-acts" style={{ marginTop: 16 }}>
    <button className="btn bs" onClick={() => setShowInviteModal(false)}>Cancelar</button>
    <button className="btn bp" onClick={handleInvite} style={{ opacity: inviteUser.isPending ? 0.6 : 1 }} disabled={inviteUser.isPending}>Convidar</button>
  </div>
</Modal>
```

### 2. Credential edit modal em `pages/app/AdminScreen.tsx` (~linha 767)

**Antes:**
```tsx
style={{ position: 'fixed', inset: 0, background: 'rgba(0,0,0,0.6)', zIndex: 1000, display: 'flex', alignItems: 'center', justifyContent: 'center' }}
```

**Depois:**
```tsx
<Modal open={!!editingIntegration} onClose={() => setEditingIntegration(null)} title={`Editar — ${editingIntegration?.name ?? ''}`}>
  {/* same content inside, without backdrop wrapper */}
</Modal>
```

### 3. Import
Adicionar no topo de AdminScreen.tsx:
```tsx
import Modal from '../../components/shared/Modal'
```

## Regras
- Substituir APENAS os overlays com `position: fixed` + `inset: 0` que servem como modais
- Manter o conteúdo interno (formulários, botões) como children do `<Modal>`
- Remover onClick do backdrop (Modal já faz isso)
- Remover estilos inline duplicados (padding, borderRadius, background) — o Modal já usa `.intg-box`
