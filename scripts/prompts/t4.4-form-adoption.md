# T4.4 — Adotar Field + .btn nos forms com style inline

## Contexto

Os componentes `Field`, `Checkbox`, `Radio`, `Toggle` existem em `components/shared/` mas não são usados. Vamos adotá-los nos forms que ainda usam style inline completo.

### 1. `pages/app/AdminScreen.tsx` — Invite modal buttons

Os 2 botões do invite modal (Cancelar, Adicionar) ainda usam style inline completo. Substituir por classes `.btn`:

**Cancelar:**
```tsx
// Antes:
<button style={{ padding: '6px 14px', borderRadius: 8, border: '1px solid var(--gb)', background: 'transparent', color: 'var(--mu)', fontSize: 12, cursor: 'pointer' }} onClick={() => setShowInviteModal(false)}>Cancelar</button>
// Depois:
<button className="btn bs" onClick={() => setShowInviteModal(false)}>Cancelar</button>
```

**Adicionar:**
```tsx
// Antes:
<button style={{ padding: '6px 14px', borderRadius: 8, border: 'none', background: 'var(--ac)', color: '#fff', fontSize: 12, fontWeight: 600, cursor: 'pointer', opacity: inviteUser.isPending ? 0.6 : 1 }} >
// Depois:
<button className="btn bp" style={{ opacity: inviteUser.isPending ? 0.6 : 1 }} >
```

### 2. `components/shared/RoutineConfigSection.tsx` — inputs com inputStyle

O arquivo define `const inputStyle = {...}` e usa em múltiplos `<input>` e `<select>` com `style={inputStyle}`. Substituir por classes CSS.

Adicionar nos inputs/selects: `className="input"` (a classe `.input` já existe em global.css).
Remover `style={inputStyle}` e manter APENAS propriedades de layout específicas (width, flex).

**Antes:**
```tsx
<input style={{ ...inputStyle, flex: 1 }} />
```

**Depois:**
```tsx
<input className="input" style={{ flex: 1 }} />
```

Se houver `<Toggle>` já importado, manter. Se não houver import, adicionar `import Toggle from './Toggle'`.

### 3. `pages/onboarding/OnboardingApp.tsx` — ScrapeField inputs

Os `<ScrapeField>` e inputs no onboarding já têm wrapper próprio. **Não modificar** — o componente ScrapeField é específico do onboarding e usa animação de digitação.

Apenas substituir botões que ainda usam style inline:
- Botões .cs-btn no onboarding.css (já tem classe .cs-btn, manter)
- Botões com style inline nas telas de scrape → verificar

## Regras
- Substituir style inline de botões por `.btn`, `.btn-p`, `.btn-s`, `.btn-ghost`
- Substituir style inline de inputs por `className="input"`
- Manter style APENAS para propriedades não cobertas pelas classes CSS
- **Não quebrar** funcionalidade existente
