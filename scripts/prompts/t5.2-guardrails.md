# T5.2 — Adicionar lint/CI guard-rails para apps/blu_v3

## Contexto
O frontend blu_v3 (`apps/blu_v3/`) não tem ESLint, nem scripts de typecheck standalone, nem job no CI.
O build (`tsc -b && vite build`) mascara erros de tipo porque `tsc -b` usa `--composite` que é menos rigoroso.
Erros como `<dc-row>` (elemento JSX inválido) só aparecem em build falho.

## Tarefas

### 1. Instalar dependências
```bash
cd /home/ec2-user/repo_platform/apps/blu_v3
npm install --save-dev \
  eslint@^9 \
  @eslint/js@^9 \
  typescript-eslint@^8 \
  eslint-plugin-react@^7 \
  eslint-plugin-react-hooks@^5
```

### 2. Criar eslint.config.js (flat config — ESLint 9)

Arquivo: `apps/blu_v3/eslint.config.js`

```js
import js from '@eslint/js';
import tseslint from 'typescript-eslint';
import reactPlugin from 'eslint-plugin-react';
import reactHooksPlugin from 'eslint-plugin-react-hooks';

export default tseslint.config(
  js.configs.recommended,
  ...tseslint.configs.recommended,
  {
    plugins: {
      react: reactPlugin,
      'react-hooks': reactHooksPlugin,
    },
    rules: {
      // Catch invalid JSX properties like <dc-row> or stroke-width
      'react/no-unknown-property': ['error', { ignore: ['dc-row'] }],

      // Enforce hooks rules
      'react-hooks/rules-of-hooks': 'error',
      'react-hooks/exhaustive-deps': 'warn',

      // Relax unused vars — tsc already catches them with noUnusedLocals
      'no-unused-vars': 'off',
      '@typescript-eslint/no-unused-vars': ['warn', { argsIgnorePattern: '^_', varsIgnorePattern: '^_' }],

      // Allow explicit any with documented justification
      '@typescript-eslint/no-explicit-any': 'warn',
    },
    settings: {
      react: { version: '18.3' },
    },
    languageOptions: {
      ecmaVersion: 'latest',
      sourceType: 'module',
      parserOptions: {
        ecmaFeatures: { jsx: true },
      },
    },
  },
  {
    ignores: ['node_modules/**', 'dist/**', 'public/**'],
  },
);
```

### 3. Atualizar package.json scripts

Adicionar ao `apps/blu_v3/package.json`:

```json
"scripts": {
  "dev": "vite --port 5175",
  "build": "tsc -b && vite build",
  "typecheck": "tsc --noEmit",
  "lint": "eslint src/",
  "lint:fix": "eslint src/ --fix",
  "preview": "vite preview"
}
```

### 4. Adicionar job ao CI

Arquivo: `.github/workflows/ci.yml`

Adicionar um job `frontend` que:
```yaml
  frontend:
    name: Frontend (blu_v3)
    runs-on: ubuntu-latest
    needs: [lint, dep-check]
    timeout-minutes: 10
    defaults:
      run:
        working-directory: apps/blu_v3
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
          cache-dependency-path: apps/blu_v3/package-lock.json
      - name: Install dependencies
        run: npm ci
      - name: TypeScript typecheck
        run: npx tsc --noEmit
      - name: ESLint
        run: npx eslint src/
```

## Critério de aceite
- `npx eslint src/` passa sem erros (warnings tolerados)
- `npx tsc --noEmit` passa
- `npm run build` passa
- CI job `frontend` está configurado e não quebra outros jobs
